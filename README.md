Restaurant Branch Performance — EDA

📌 Overview

This project performs Exploratory Data Analysis (EDA) on a Restaurant Branch Performance dataset using Python, Pandas, Matplotlib, and Seaborn.

The analysis explores customer activity, revenue, profit, marketing spend, staff count, delivery time, ratings, and performance differences across branches, regions, and store types.

📊 Analysis Covered

Dataset structure and data quality

Missing values and duplicate records

Summary statistics and descriptive analysis

Numerical variable distributions

Outlier analysis

Branch-wise performance

Region-wise performance

Store-type comparison

Customer, order, revenue, and profit relationships

Marketing spend analysis

Delivery time and customer rating analysis

Correlation matrix and heatmap

Key business insights and observations

🚀 How to Run

1. Clone/download this repository.


2. Open Restaurant_Branch_Performance_EDA.ipynb in Jupyter Notebook or Google Colab.


3. Make sure the CSV dataset is available in the same directory.


4. Run the notebook cells sequentially.



🎯 Objective

The main objective is to identify patterns, relationships, performance differences, and actionable business insights from restaurant branch data through exploratory data analysis.
